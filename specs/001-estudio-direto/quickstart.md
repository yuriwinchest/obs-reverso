# Validação e início
1. npm ci; npm run assets; npm run build; npm start. Para desenvolver: npm run dev.
2. Iniciar câmera/mic e verificar seletores, mute e medidor. Escolher desfoque, imagem, cor e ambiente animado. Verificar recorte real com cabelo/movimento.
3. Compartilhar tela via seletor explícito, parar no app e no sistema; conferir retorno e áudio real.
4. Gravar 10s, finalizar e reproduzir; testar cancelar diálogo.
5. npm test e npm run smoke: ensaio sintético no Electron e encoder local, sem envio externo. Examinar artifacts.
6. Configurar OAuth desktop Google em Destino (arquivo escolhido por diálogo, nunca Git), conectar no navegador. Ou colar chave no campo protegido.
7. Live privada real e homologação visual/áudio pelo Yuri são gate externo; não executadas automaticamente.
8. npm run package gera pasta Windows com aplicativo e dependências. Assinatura comercial não configurada.
